# Proyectos prácticos

Los proyectos de esta carpeta son puntos de partida ejecutables para experimentar con distintas aplicaciones de Python. Cada proyecto debe crecer de forma gradual: primero se ejecuta, luego se modifica y finalmente se amplía.

## Proyectos iniciales

| Proyecto | Requisito | Qué permite practicar |
|---|---|---|
| [Tkinter: primera ventana](interfaces/tkinter_primera_ventana.py) | Python con Tkinter | Ventana, etiqueta, botón y eventos |
| [CustomTkinter: primera aplicación](interfaces/customtkinter_inicio.py) | Instalar `customtkinter` | Ventana moderna, botón y función de respuesta |
| [Pygame: mover un objeto](juegos/pygame_mover_objeto.py) | Instalar `pygame` | Eventos, coordenadas, teclado y bucle principal |
| [Reporte CSV](automatizacion/reporte_csv.py) | Python estándar | Lectura de CSV, validación y resumen |
| [Gráfica de datos](datos/grafica_datos.py) | Instalar `matplotlib` | Leer datos y producir una gráfica |

## Preparación del entorno

Antes de instalar bibliotecas externas, sigue la [guía de entorno virtual e instalación](../GUIA_ENTORNO.md). Instala únicamente las dependencias del proyecto que vayas a ejecutar.

## Cómo ejecutar

1. Abre la carpeta del proyecto en Visual Studio Code.
2. Revisa las instrucciones del archivo y sus dependencias.
3. Si necesita una biblioteca externa, crea un entorno virtual e instala solo esa biblioteca.
4. Ejecuta el archivo indicado desde la terminal.
5. Cambia un valor, predice el resultado y vuelve a ejecutar.
6. Resuelve al menos un reto antes de pasar al siguiente proyecto.

Los ejemplos son una base de aprendizaje, no aplicaciones terminadas ni evidencia de pruebas en todos los sistemas operativos. La ejecución de interfaces gráficas requiere un entorno de escritorio compatible.
