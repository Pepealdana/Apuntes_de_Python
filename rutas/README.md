## Forma de trabajo

Cada ruta debería terminar con un proyecto que se pueda ejecutar, explicar, probar y mejorar. No se considera terminada solo porque tenga un ejemplo de código.

Para cada proyecto se documentarán:
- objetivo y resultado esperado;
- estructura de archivos;
- preparación e instalación;
- instrucciones para ejecutar;
- explicación de las partes importantes;
- retos graduados;
- pruebas realizadas y limitaciones;
- ideas de ampliación.

## Antes de instalar una biblioteca

1. Comprueba qué versión de Python tienes.
2. Crea un entorno virtual para el proyecto si vas a instalar dependencias.
3. Instala únicamente los paquetes necesarios.
4. Ejecuta un ejemplo mínimo.
5. Registra las instrucciones en el README del proyecto.

Las rutas están pensadas para herramientas gratuitas. No se presupone que todos los computadores tengan permisos de administrador ni conexión permanente a internet.
