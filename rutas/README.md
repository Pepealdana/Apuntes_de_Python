## Forma de trabajo

Cada ruta debe terminar con un proyecto que se pueda ejecutar, explicar, probar y mejorar. No se considera terminada solo porque tenga un ejemplo de código.

Cada proyecto debe documentar:
- objetivo y resultado esperado;
- estructura de archivos;
- preparación e instalación;
- instrucciones para ejecutar;
- explicación de las partes importantes;
- retos graduados;
- pruebas realizadas y limitaciones;
- fuentes oficiales relevantes.

Antes de instalar una biblioteca, revisa la [guía de entorno virtual e instalación](../GUIA_ENTORNO.md). Las rutas están pensadas para herramientas gratuitas y equipos modestos; no se presupone conexión permanente ni permisos de administrador.
