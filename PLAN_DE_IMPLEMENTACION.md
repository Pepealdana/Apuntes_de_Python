## Criterios para marcar un proyecto como verificado

Un proyecto solo se marcará como verificado cuando:
1. el código se haya ejecutado en el entorno indicado;
2. se haya probado el flujo principal;
3. se hayan probado al menos los casos de error más relevantes;
4. las instrucciones de instalación y ejecución coincidan con lo observado;
5. cualquier limitación conocida quede documentada.

La compilación automática comprueba sintaxis; no demuestra que una interfaz se vea correctamente ni que un juego, API o integración funcione en el equipo del estudiante.
