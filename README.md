# Apuntes de Python

Ruta progresiva para aprender Python mediante conceptos breves, ejemplos ejecutables, retos y pequeños proyectos.

## Objetivo

Construir una base sólida de programación y avanzar hacia aplicaciones de escritorio con **CustomTkinter**, análisis de datos y simuladores educativos.

## Cómo trabajar cada sesión

1. Lee los conceptos clave.
2. Ejecuta el ejemplo sin modificarlo.
3. Cambia algunos valores y predice qué ocurrirá.
4. Resuelve el reto sin copiar la solución.
5. Registra qué aprendiste y qué dudas quedan.

## Ruta de aprendizaje

| Etapa | Contenidos |
|---|---|
| 1. Fundamentos | Sintaxis, variables, tipos de datos, operadores, salida y entrada |
| 2. Control de flujo | Condicionales, bucles y validación |
| 3. Estructuras de datos | Cadenas, listas, tuplas, diccionarios y conjuntos |
| 4. Funciones y módulos | Funciones, alcance, módulos y organización |
| 5. Calidad del código | Excepciones, archivos, depuración y pruebas |
| 6. Interfaces gráficas | Tkinter y CustomTkinter |
| 7. Datos y visualización | CSV, estadísticas y gráficas |
| 8. Proyectos integradores | Simuladores educativos y comunicación con Arduino |

## Entorno recomendado

- Python 3
- Visual Studio Code
- Extensión oficial de Python para VS Code

Las sesiones iniciales no requieren bibliotecas externas. CustomTkinter se incorporará cuando empecemos la etapa de interfaces gráficas.
